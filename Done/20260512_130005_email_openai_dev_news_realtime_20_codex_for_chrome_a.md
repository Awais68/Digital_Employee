*A new wave of voice intelligence*

We’re excited to announce three new models in the Realtime API that help you build smarter voice agents that feel more natural in conversation and can take action live as speech is happening:

* *gpt-realtime-2 ( https://developers.openai.com/api/docs/models/gpt-realtime-2 ) :* Smarter voice agents with stronger instruction following, prompt adherence, and multilingual capabilities
* *gpt-realtime-translate ( https://developers.openai.com/api/docs/models/gpt-realtime-translate ) :* Translate conversations live across 70 input languages and 13 output languages
* *gpt-realtime-whisper ( https://developers.openai.com/api/docs/models/gpt-realtime-whisper ) :* Transcribe each word as its spoken rather than waiting for a sentence to finish

It’s one of those things you have to see (and hear) for yourself. Check it out in action ( https://x.com/OpenAI/status/2052438194625593804 ) and try it in the playground. ( https://platform.openai.com/login?next=%2Faudio%2Frealtime )

*Codex can now use Chrome directly*

So much work happens in browser tabs. The new Chrome extension ( https://x.com/OpenAIDevs/status/2052481136971125158 ) builds on computer use, so Codex can work directly inside sites where you’re signed in, organize task-specific tabs, and hand back results for review.
